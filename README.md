# CAG - NED University

Coursework, notes, and problem sets for Calculus and Analytic Geometry (CAG) at NED University of Engineering & Technology.

## 📁 Structure
- `lectures/` — Lecture notes and slides
- `assignments/` — Homework and problem sets
- `past-papers/` — Previous exam papers and solutions
- `resources/` — Reference material, YouTube links, extra practice

## 🎯 Topics Covered
- Limits and continuity
- Differentiation and applications
- Integration techniques
- Sequences and series
- Analytic geometry (conics, vectors)

## 🤝 Contributing
Fellow students are welcome to open PRs for corrections or additional notes. Please keep formatting consistent.

## ⚠️ Disclaimer
This repo is meant for learning and reference only. Please don't copy-paste for graded submissions — use it to understand concepts.
